# just the original five. Deliberately excludes spacy, rapidfuzz and

# en_core_web_sm download alone adds real image size and build time that a
# free-tier host's build minutes should not pay for.
#

# enforces this split, so if the API gains a new import, add it here too.
#

# local_translation.py use them, both lazily inside functions, and both are
# off in the Nectar deployment. See Dockerfile.serve.
